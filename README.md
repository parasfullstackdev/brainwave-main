# Brainwave

**Brainwave** is a fully responsive website built with React and Tailwind CSS, designed to provide a seamless user experience across all devices. Whether you're on a phone, tablet, or desktop, the website adapts beautifully to any screen size.


## Features

- Fully responsive design, optimized for mobile, tablet, and desktop views.
- Built with **React** for efficient rendering and component management.
- Styled using **Tailwind CSS** for a modern and flexible UI.
- Interactive user interface with smooth animations and transitions.

## Tech Stack

- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for styling the components.
- **JavaScript (ES6+)**: For scripting and handling dynamic content.
- **Vite**: For fast and optimized development build.
